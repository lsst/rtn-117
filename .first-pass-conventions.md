# First-pass review conventions (RTN-117)
- Use "Instrument Signal Removal" (not "Instrument Signature Removal"); lowercase "instrument signal removal (ISR)" in running text, Title Case in section titles
- Use "E2V" (not "e2v"); "Teledyne e2v" full vendor name stays as is
- Use "flat field" (noun) and "flat-field" (adjective), "flat-fielding" (not "flatfield", "flatfields")
- Use "$y$-band" style for filter bands, e.g. "$z$- and $y$-band" (not "y-band", "$y$ band")
- Use "Simonyi Survey Telescope" (not "Simonyi Telescope")
- Use "Flat-Field Illuminator" for the flat-field hardware (not "Flatfield Calibration System", "flat calibration system")
- Use "mmag" next to numbers, "millimag" as a bare adjective (e.g. "millimag precision")
- Use "$2{,}500~\mathrm{deg}^{2}$" for sky-area units (not "2,500~deg$^{2}$")
- Define acronyms in the body at first use even if defined in the abstract
